Why Python, of all languages?

Imagine two people writing the same sentence — one in shorthand only they understand, another in plain English anyone can read. That's the difference between most programming languages and Python.

  • Reads almost like plain English — print("hi") really does mean "print hi".
  • No semicolons, no curly braces — spacing itself is the grammar.
  • Runs everything from Instagram's backend to NASA's data pipelines to the AI writing this sentence.
  • Huge beginner community — someone has already asked (and answered) your doubt online.
02
🧠

What even is "programming"?

Programming is just writing a recipe for a very obedient, very literal chef — your computer. It will do exactly what you say, in the exact order you say it, and not one step more.

Tell it "add sugar" before "boil water," and it will happily add sugar to an empty pan. So a program is simply: a clear list of instructions, written in a language the computer understands, to get a result.

03
🖨️

Meet print() — your first word

Every language you learn starts with saying something out loud. In Python, that first sentence is the print() function.

print(value, value2, ..., sep=" ", end="\n")

Anything inside the round brackets gets displayed on screen. Text always goes inside quotes ("like this"); numbers don't need quotes at all.

04
📦

What is a variable?

A variable is a labelled box. You choose a name for the box (say, age), drop a value inside it (19), and Python remembers it for you.

box_name = value

Later you just say the box's name, and Python hands you back whatever is inside — no need to retype the value again and again.

05
⌨️

Input & operators — Python starts listening

input() pauses the program and waits for the user to type something. Whatever they type comes back as text (a string) — even if it looks like a number.

Operators are the math/logic symbols: + − × ÷ // % ** for arithmetic, and > < == != for comparisons. Combine input() with int()/float() and operators, and your program finally reacts to a real human.

Unit 1

Say it with print() — 10 programs

🎯 The concept, in one breath

print() is a built-in function — a ready-made tool Python gives you — whose only job is to display things on screen. You "call" it by writing its name followed by round brackets, and you put whatever you want shown inside those brackets.

Two quiet superpowers hide inside it: the sep parameter decides what goes between multiple items (default is a space), and the end parameter decides what comes after everything (default is a new line). Master those two, and you control exactly how your output looks.

print(value1, value2, ..., sep=" ", end="\n")
Unit 2

Boxes that remember — 10 variable programs

🎯 The concept, in one breath

A variable is created the moment you assign it a value with =. No separate "declare" step, no fixed type — Python figures out on its own whether your box holds text, a whole number, a decimal, or a True/False.

Naming rule of thumb: start with a letter or underscore, use only letters/numbers/underscores after that, and pick a name that actually describes what's inside — age is a far better box label than x.

variable_name = value # no operators yet, just storing & showing
Unit 3

Ask, calculate, react — 12 input & operator programs

🎯 The concept, in one breath

input("message") shows the message, waits for the user, and hands back whatever they typed — always as text. If you want to do math with it, wrap it in int() (whole numbers) or float() (decimals) first.

Then the operators take over: + − * / for the basics, // for floor (whole-number) division, % for the remainder, ** for power, and > < == != to compare two values and get back True or False.

variable = int(input("Enter a number: "))
